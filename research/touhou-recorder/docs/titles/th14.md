# 東方輝針城 (th14)

## 基本情報

- 版: ver1.00b(非Steam版、CDリッピングデータ+公式アップデータ)。Steam版(`games/th14_steam`、reports/04)とは別物
- 画面解像度: 1280x960 (4:3)。th15・th20と同じ960p
- 描画API: Direct3D9 / 入力: DirectInput(`GetDeviceState`、PressKeyで注入)
- VsyncPatch・thpracは不要(使わない)
- 推奨クラウドスペック: **GPU `g6f.2xlarge` の2倍速**(`--gpu-display --gpu-encode`)。CPUのフォールバックは`c7i.4xlarge`の1/2倍速。CPUの等倍は不可

## 固有仕様・運用ルール

- **cfg/replay**: `%APPDATA%/ShanghaiAlice/th14/`から読む(`GameConfig.appdata_dir`・`cfg_filename`で配置)。リプレイは`th14_ud0000.rpy`に正規化
- **th14.cfg**: オフセット0x39が「起動時に毎回訊ねる」。1だと起動時に解像度選択ダイアログが出て録画が止まるので**0にする**(`games/th14/th14.cfg`は0に変更済み、元は`th14.cfg.orig`)。画面サイズは0x1F(5=1280x960)
- **メニュー操作**(MOD): 起動後10秒待つ → Down×3 → Enter(Replay、Extra未解放のため「Extra Start」はスキップ) → Right → Enter → Enter
- **終了検知**: 画面静止検知のみ。`still_detect_exclude_rect=[(85,426,85+295,426+429)]`。1280x960なのでサブストリーム方式(`poll_side_stream=True`)
- **スコア**: 内部値×10=表示値(リプレイ記録値と通常・Extraとも一致)。ステージ番号は1始まり(Extraは7)。score=`0x4f5830`、stage=`0x4f58a4`、lives=`0x4f5864`、graze=`0x4f5840`
- **fps表示の補正**: `InstallFpsDisplayCorrectionHookViaCaller(0x0006ac5e, 0x0002e4e0)`(th15と同じ構造)。`SPEED_HACK_MULTIPLIER`を併用する低速・倍速ではQPC偽装だけで等倍換算になる
- **GPU描画面のCRTCモードは`1400x1050`**(`GameConfig.crtc_mode`)。`1280x960`だとウィンドウが1280x940に縮む
- **CPU描画の律速**: llvmpipeの塗りつぶし。弾消しエフェクト(Extraの約510秒地点)やLunatic 4面で、16スレッドでも等倍で14〜22Hzまで落ちる。1/2倍速でもその数秒間は目標30Hzに届かない
- 低速録画は`FPS_LIMIT_TARGET_HZ=30 SPEED_HACK_MULTIPLIER=0.5`(1/3倍速は`20`と`0.3333333`、`--max-duplicate-rate 95`が必要)。倍速は`FPS_LIMIT_TARGET_HZ=120 SPEED_HACK_MULTIPLIER=2`

## 実測(reports/103)

落ち率は等倍へ戻した60fps動画のプレイ区間。括弧内は30秒窓の最悪。

| 環境 | Extra(th14_08) | Lunatic全クリア(th14_22) |
|---|---|---|
| ローカル 等倍 | 5.7%(22.2%) | 4.2%(27.2%) |
| c7i.2xlarge 等倍 | 17.0% | 未実施 |
| c7i.4xlarge 等倍 | 5.8%(21.3%) | 4.9%(27.6%) |
| c7i.2xlarge 1/2倍速 | 2.9%(12.4%) | 2.0%(16.9%) |
| c7i.4xlarge 1/2倍速 | 0.8%(4.4%)、最小22.2Hz | 0.7%(8.6%)、最小14.6Hz |
| c7i.2xlarge 1/3倍速 | 0.9%(3.3%) | 未実施 |
| c7i.4xlarge 1/3倍速 | 0.3%(1.2%) | 未実施 |
| g6f.2xlarge 等倍 | 0.0%(0.1%) | 0.0%(0.2%) |
| g6f.2xlarge 2倍速 | 0.2%・0.1%(2回) | 0.2%(魔理沙B Lunaticも0.2%) |
| g6f.2xlarge 3倍速 | 5.8%(キャプチャが律速) | 未実施 |

全録画でスコア一致・同期残差±1.0ms以内。判定は数値のみで、視聴確認は未実施。
