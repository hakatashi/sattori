# 東方錦上添花 (th20)

## 基本情報

- 画面解像度: 1280x960相当 (4:3)
- 描画API: Direct3D9
- 推奨クラウドアスペクト: **16 vCPU (`.4xlarge`帯、`c7i.4xlarge`)**

## 固有仕様・運用ルール

- **エンジン・設定配置**: 設定ファイルおよびリプレイは `%APPDATA%/ShanghaiAlice/th20/`（WINEPREFIX内）に配置されます。
- **画面解像度・待機時間**: 内部描画解像度が1280x960相当のため、`xvfb_screen` には `1400x1100` などの大きめのサイズを指定します。タイトルロゴ完了まで10秒程度長めに待機します。
- **入力方式**: Win32 の `GetKeyboardState` でポーリングします。
- **thpracの必須実行とタイムアウト延長**: リプレイデシンク対策のため、録画時は必ず `--thprac` を指定します。またスコアアタック系リプレイの尺確保のため `TIMEOUT_SEC` を5400秒程度に延長します。
- **クラウド必要スペック**: 高負荷シーンでの処理落ちを防ぐため、`.4xlarge` 帯（`c7i.4xlarge`）を使用します（`.2xlarge` 帯では処理落ちが発生します）。
- **スコア監視**: スコア倍率は ×10。
- **メモリスキャンの注意**: 診断用差分メモリスキャンはゲームをフリーズさせるリスクがあるため、`STAGE_PROBE_MEM=0` でIO観測のみに制限します。
- **ステージ開始時刻検出**: アセットロードバースト検出方式に対応しています。
- **リプレイ終了検知**: 画面静止検知のみで運用し、`still_detect_exclude_rect` で明滅・アニメーション領域を除外します。

- **CPU低速録画(reports/91)**: `c7i.4xlarge`の1/2倍速(`FPS_LIMIT_TARGET_HZ=30`)で配信版の落ち0.7〜0.8%・理論尺比+0.18〜+0.32%・実時間は尺の2.03〜2.04倍。`.2xlarge`は落ち2.0〜2.8%で非推奨。低速の2並列でのハング(sattori-dev#179)は未解決なので、自宅ワーカーで並列に動かさない。

- **CPU描画の律速(reports/99)**: llvmpipeの塗りつぶしそのもので、CPU量にほぼ比例する。テクスチャは全てA8R8G8B8で遅い形式は無い。ゲーム本体のスレッドはth15の約3倍重い(平均40%)が、落ち込み時も律速ではなかった。**画面サイズはth20.cfgのオフセット0x78**(4=960x720、5=1280x960)。960x720にすると4コア8スレッドで1280x960の8コア16スレッドと同等(Lunatic 平均89.1Hz・下位5% 55.4)になるが、画質が下がるため未採用。MODのmingwビルドは`mods/th20_replay_autoplay/build_mingw.sh`(`build.bat`は`speed_hack_hook.cpp`が漏れていて古い)。
