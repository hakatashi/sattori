# 東方神霊廟 (th13)

## 基本情報

- 版: ver1.00c(非Steam版、CDリッピングデータ+公式アップデータ)。Steam版(`games/th13_steam`、DRMで起動不可、reports/04)とは別物
- 画面解像度: 640x480 (4:3)
- 描画API: Direct3D9 / 入力: DirectInput(`GetDeviceState`、PressKeyで注入)
- VsyncPatchは不要(使わない)
- 推奨クラウドスペック: **8 vCPU (`c7i.2xlarge`) + 1/2倍速録画**。等倍は`c7i.4xlarge`でもExtraが基準外

## 固有仕様・運用ルール

- **cfg/replay**: `%APPDATA%/ShanghaiAlice/th13/`から読む(`GameConfig.appdata_dir`・`cfg_filename`で配置)。リプレイは`th13_ud0000.rpy`に正規化
- **メニュー操作**(MOD): 起動後10秒待つ → Down×3 → Enter(Replay、Extra未解放のため「Extra Start」はスキップ) → Right → Enter → Enter
- **終了検知**: 画面静止検知のみ。`still_detect_exclude_rect=(48,220,48+159,220+212)`
- **スコア**: 内部値×10=表示値(リプレイ記録値と通常・Extraとも一致)。ステージ番号は1始まり(Extraは7)
- **fps表示の低速補正は未対応**(画面右下の「60.0fps」は1/2倍速でも30前後を示すはず)。必要ならtimer_probe_hookで呼び出し元RVAを特定する
- **Spot中断**: `c7i.xlarge`で1回中断された(eu-south-2)。録画1本ごとに成果物を回収すること
- 録画はラベル付きバッチ`scripts/100_run_th13_cloud_batch.sh`、1/2倍速は`FPS_LIMIT_TARGET_HZ=30 SPEED_HACK_MULTIPLIER=0.5`を環境変数で渡す

- 会話文・スペルカード名は GDI で 2 倍の大きさ(MS ゴシック height=32)に描き、`D3DXLoadSurfaceFromMemory`(`D3DX_FILTER_TRIANGLE`)で縮小転送している。Wine の D3DX は最近傍で縮小するため文字がジャギーになる。`D3DX_AREA_FILTER=1` で MOD 側の面積平均に置き換えると Windows 実機とほぼ同じになる(既定は無効、reports/101)。AWS の `c7i.2xlarge` 1/2倍速で、フィルタの有無による品質差は無かった(各2回、落ち0.4〜0.6%、reports/102)。
