# 東方紅魔郷 (th06)

## 基本情報

- 画面解像度: 640x480 (4:3)
- 描画API: Direct3D8
- 推奨クラウドアスペクト: 4 vCPU (`c7i.xlarge` 等)

## 固有仕様・運用ルール

- **環境変数**: `LANG=ja_JP.UTF-8` の指定が必須。
- **vpatchの同時注入**: MODより前に `vpatch_th06.dll` を注入することが必須。`mods/common/injector.cpp` は `injector.exe <exe> <dll1> [dll2 ...]` による複数DLL注入に対応済み。
- **プロセス名の切り詰め**: 実行ファイル名（`東方紅魔郷.exe`）は `/proc/PID/comm` の15バイト制限により `東方紅魔郷` に切り詰められる。`pgrep -x`/`pkill -x` はこの切り詰め後の名前を使用する（`recorder/games.py` の th06 の `process_name` 参照）。
- **リプレイ終了検知**: 画面静止検知に加え、リプレイ選択画面のテンプレート画像照合を併用（`assets/replay_end_templates/`）。
- **スコア監視**: スコア倍率は等倍（×1）。
