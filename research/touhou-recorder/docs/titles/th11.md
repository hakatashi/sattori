# 東方地霊殿 (th11)

## 基本情報

- 画面解像度: 640x480 (4:3)
- 描画API: Direct3D9
- 推奨クラウドアスペクト: **8 vCPU / 16 GiB以上 (`.2xlarge`帯、`c7i.2xlarge`推奨)** が必須

## 固有仕様・運用ルール

- **クラウド必要スペック**: 4 vCPUではCPU世代を問わず処理落ちするため、8 vCPU / 16 GiB以上の `.2xlarge` 帯が必須です。
- **入力方式**: DirectInputではなく、Win32 の `GetKeyboardState` でポーリングします（`mods/common/dinput_hook.h` の `InstallKeyboardStateHook`/`PressVKey` で対応）。
- **ウィンドウ座標**: openboxの初期ウィンドウ配置が画面外にはみ出すことがあるため、検出後に(0,0)へ強制移動して再取得する処理を行っています。
- **リプレイ終了検知**: 画面静止検知のみで運用し、`still_detect_exclude_rect` で明滅・アニメーション領域を除外します。
- **スコア監視**: スコア倍率は ×10。

- **文字のジャギー(reports/101・102)**: 会話文・スペルカード名は `D3DXLoadSurfaceFromMemory`(730x36→354x17、`D3DX_FILTER_TRIANGLE`)の縮小転送で、Wine では最近傍になる。`D3DX_AREA_FILTER=1` で MOD 側のテント縮小に置き換わる(既定は無効)。Extra のフル尺で表示の崩れなし。`c7i.2xlarge` 等倍の AWS 比較(各2回)で、フィルタの有無による品質差は無かった(落ち あり0.7・1.1% / なし1.9・1.4%)。
