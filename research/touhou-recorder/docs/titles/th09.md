# 東方花映塚 (th09)

## 基本情報

- 画面解像度: 640x480 (4:3)
- 描画API: Direct3D8 (対戦形式)
- 推奨クラウドアスペクト: 4 vCPU (`c7i.xlarge` 等)

## 固有仕様・運用ルール

- **ウィンドウ移動のスキップ**: 検出後の(0,0)強制移動を行うと録画中盤以降にタイトルバーが混入する不具合があるため、`recorder/games.py` の th09 に `skip_origin_move_if_fits=True` を指定して移動をスキップします。
- **fps暴走検知閾値の上書き**: 健全な状態でも `GetDeviceState` ポーリングが100〜190Hz程度に達するため、既定閾値（100Hz）で誤検知しないよう `recorder/games.py` の `fps_runaway_hz_threshold` で上書きしています（300Hz）。
- **Direct3D8版低速録画**: Direct3D8エンジンのため、低速録画には `mods/common/fps_limiter_hook_d3d8.h` を使用します。Present間引きのビジーウェイトがCPUを占有しウィンドウ安定待ちの実時間が延びるため、録画パイプライン（`recorder/timing.py`）・MOD側ともに `MENU_TIME_SCALE`/`GetMenuTimeScale()` で全タイムアウトをスケールします。
- **画面上fps表示補正**: 低速録画時のfps表示補正対象は `WINMM.dll!timeGetTime` (rva=0x00031701) です（`mods/common/fps_display_hook.h` の `InstallFpsDisplayCorrectionHookTimeGetTime`）。
- **リプレイ終了検知**: リプレイ選択画面のテンプレート画像照合を併用します（可変領域は `end_template_rect` で除外）。
- **内部変数状況**: 残機（`life`, `pl+0xa8`）は特定・実装済みですが、スコア変数のRVAは未特定です。
