# th20 のスペルカード名をゲームアセット(ECL)から抽出する

- **検証日**: 2026-11-28
- **対象**: th20(東方錦上京)の `th20.dat` 内のステージ別 ECL。リプレイパーサのスペルカード名テーブル
  (`packages/replay-parser/src/data/th20/spellcards.json`、113エントリ)の裏取り
- **環境**: 自宅ワーカー機。`worker/games/th20/th20.dat` を THA1 展開スクリプトで展開(ゲームは起動していない)
- **結論**: **th13・th14 と同じ鍵(0x77・7・16 のローリング XOR、cp932)で th20 の ECL からも全名前を復号でき、
  画面から書き起こした名前51種と両方向で完全一致した。** 番号と難易度の対応は画面(Player Data)から取った

手順は [`2026-11-28-spell-card-names-from-ecl.md`](2026-11-28-spell-card-names-from-ecl.md) と同じで、鍵の再探索は不要だった。
th20 の `th20.dat` も THA1 形式で、同じ展開スクリプトで `common.ecl`・`default.ecl`・`st01`〜`st07` 系の ECL が出る。

## 結果

- ECL から復号した名前(重複除く): 51。画面の表の名前(重複除く): 51。差: 0(両方向)。
- 番号体系: No.1〜100 は4つ1組(Easy=4k+1・Normal=4k+2・Hard=4k+3・Lunatic=4k+4)、No.101〜113 が Extra。
  難易度で名前が変わるのは、塵符(コズミックダスト→宇宙塵、唐櫃返し→唐櫃大返し)、魅符・魑符(沢・森・山の気)、
  謎符(ピラミダル→ヘキサゴナル)、塞符(ロジカルウォール→ロジカルグレートウォール)、虚符・群符(ビッグデータ・マリオネット)、
  災禍(山津波→長い山津波→終わらない山津波。Hard と Lunatic でも違う)、死符(永遠→恒久の冬)、
  「ストーンゴッデス」→「不生不滅の石の女神」(Hard 以上)。
- 既存フィクスチャの実リプレイと整合: No.40(Lunatic 金符「弾幕の金字塔」)、No.100(Lunatic「不生不滅の石の女神」)、
  No.112(Extra「チョコレートリバー」)。

## 考察・既知の限界

- 東方Wikiなど Web 上の有志情報との照合は th20 では行っていない(ECL=ゲーム自身のデータとの一致で名前は確定)。
  番号・難易度の対応は画面の書き起こしのみが根拠(14枚、No.1〜113 の全件)。
- th15〜th18・th128 など他タイトルでの同手法の適用は未確認。
