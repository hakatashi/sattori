# th13(東方神霊廟 ～ Ten Desires.)対応の技術的背景(Issue #79、touhou-recorder reports/100)

**ver1.00cの非Steam版**(CDのデータ+公式アップデータ)で録画する。Steam版はDRM(`steamclient.dll`)で
起動直後に終了するため使えない(touhou-recorder reports/04)。sattori本体の`record_th13.py`での検証結果は
[`docs/reports/2026-11-12-th13-recording-verification.md`](../../../docs/reports/2026-11-12-th13-recording-verification.md)、
録画の段(どこで・どの速度で録るか)の判断は
[`decisions/0070`](../../../docs/decisions/0070-th13-native-on-4xlarge-and-half-speed-on-2xlarge.md)。

- **入力注入はth10/th12/th128と同じPressKey(DIKスキャンコード経由)**。`th13.exe`はDINPUT8を
  インポートし、`GetDeviceState`を60Hzで呼ぶ(MODログの`FpsMonitor`で確認、reports/100)。
- **メニュー操作は「10秒待つ → Down x3 → Enter → Right → Enter → Enter」**。Down x3なのは、未解放の
  「Extra Start」をカーソルが飛ばすため。**タイトル資産のWINEPREFIXにExtraを解放したスコアファイル
  (`%APPDATA%/ShanghaiAlice/th13/scoreth13.dat`)を入れないこと**——カーソルの止まる位置が変わり、
  Replayに着地しない。資産はスコアファイル無しで固めてある(`upload-title-assets` skillの`titles.md` §13)。
  リプレイ鑑賞ではExtraは解放されないので、自宅ワーカーのキャッシュに溜まるスコアファイルは無害。
  起動直後のロード画面をタイトル画面と取り違えないよう、待ちは10秒取っている。
- **cfg/リプレイは`%APPDATA%/ShanghaiAlice/th13/`から読む**(`uses_appdata_profile=True`、th128・th20と同じ)。
  `th13.cfg`はウィンドウモード(先頭付近のバイトで確認済み)のものを`games/th13/`に同梱する。
- **VsyncPatch・thpracは使わない**。VsyncPatch無しでもローカル・AWSとも60Hzで安定する。thpracは
  スコア監視のRVAの参照元(`thprac_th13.cpp`)として使っただけ。等倍でもMODの`fps_limiter_hook`が
  Presentを60fpsに制限する(th128と同じ)。
- **終了検知は画面静止検知のみ**。リプレイ終了後のメニューの明滅を
  `still_detect_exclude_rect=(48, 220, 207, 432)`で除外する(reports/100)。
- **スコア監視**: score=RVA`0xbe7c0`(内部値は表示値の1/10)、stage=+0x5c(1始まり、Extraは7)、
  lives=+0x34、graze=+0x10。通常(Hard全クリア)・Extraでリプレイの記録スコアと完全一致(reports/100)。
- **低速録画はPresentの上限とQPC偽装の両方で減速する**(`slow_motion_speed_hack=True`)。ゲームの
  フレーム待ちと画面右下のfps表示がQPC基準なので、揃えて減速すると表示も「60.0fps」のまま出る
  (th15・th20はPresentの上限だけで減速し、fps表示を専用フックで補正している)。reports/100の
  1/2倍速もこの構成で検証した。
- **処理落ちはCPU性能に敏感**。等倍は`c7i.2xlarge`でExtraの落ち6.3%、`c7i.4xlarge`でも4.3%
  (reports/100)。自宅ワーカー機(Ryzen 7 5700X)では0.6%。GPUでの倍速は未検証。
