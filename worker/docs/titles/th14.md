# th14(東方輝針城 ～ Double Dealing Character.)対応の技術的背景(Issue #80、touhou-recorder reports/103・110)

**ver1.00bの非Steam版**(CDリッピング+公式アップデータ`th14_update100b.exe`適用済み)で録画する。Steam版
(touhou-recorder `games/th14_steam`)は別物なので使わない。録画の段は**CPUのフレーム同期のみ**
(自宅→`c7i.4xlarge`→`.2xlarge`帯)で、GPUの段は持たない(GPUインスタンスでの録画が検証できていない)。
段の判断は[`decisions/0085`](../../../docs/decisions/0085-th14-frame-sync-plan-without-gpu.md)、検証結果は
[`docs/reports/`](../../../docs/reports/README.md)の`th14`の項。

th13と同じ`t13r`系のリプレイ(パーサーは`th13-14.ts`)だが、エンジンの世代はth15・th20に近く、
**内部描画解像度は1280x960**(th15・th20と同じ。`xvfb_screen="1400x1100x24"`)。

- **入力注入はth13・th15と同じPressKey(DIKスキャンコード経由)**。`th14.exe`はDINPUT8・DSOUND・d3d9・
  d3dx9_43をインポートし、`GetDeviceState`を60Hzで呼ぶ。
- **メニュー操作は「10秒待つ → Down x3 → Enter → Right → Enter → Enter」**(th13と同じ)。Down x3なのは未解放の
  「Extra Start」をカーソルが飛ばすため。**タイトル資産のWINEPREFIXにExtraを解放したスコアファイル
  (`%APPDATA%/ShanghaiAlice/th14/scoreth14.dat`)を入れないこと**——カーソルの止まる位置が変わりReplayに
  着地しない(`upload-title-assets` skillの`titles.md`)。
- **`th14.cfg`のオフセット0x39は「起動時に毎回訊ねる」**。1だと起動時に解像度選択ダイアログ(179x140)が出て
  止まる。0にしておく(`games/th14/th14.cfg`は0に直したものを同梱する。元のcfgは1だった)。画面サイズはth15と同じ
  0x1F(5=1280x960)。
- **cfg/リプレイは`%APPDATA%/ShanghaiAlice/th14/`から読む**(`uses_appdata_profile=True`)。
- **終了検知は画面静止検知のみ**。リプレイ終了後のメニューの明滅を
  `still_detect_exclude_rect=[(85, 426, 380, 855)]`で除外する(1280x960のウィンドウ座標系、reports/103)。
- **スコア監視**(`thprac_th14.cpp`): score=RVA`0xf5830`(内部値は表示値の1/10)、graze=+0x10、lives=+0x34、
  stage=+0x74(1始まり、Extraは7)。Extra・Lunatic全クリアでリプレイの記録スコアと完全一致(reports/103・110)。
- **fps表示の補正**(倍速・低速のときの実時間の経路だけで効く): `InstallFpsDisplayCorrectionHookViaCaller(0x6ac5e,
  0x2e4e0)`(構造はth15と同じ、reports/93・103)。フレーム同期では使わない。
- **文字の縮小フィルタ(`d3dx_filter`)は組み込まない**。th10〜th13の文字ジャギーは640x480→拡大の問題で、
  1280x960のth14は対象外の可能性が高い(reports/103 §8)。
- **VsyncPatch・thpracは使わない**。

## CPU描画の速度(参考)

等倍の実時間のCPU描画は不可(ローカル・`c7i.4xlarge`とも落ち4.2〜5.8%。th15と同じ1280x960の塗りつぶしが律速)だったが、
フレーム同期なら落ちは原理的に起きず遅くなるだけ(ローカル16スレッドで1.17〜1.38倍速、8スレッド相当で0.92倍速、
4スレッド相当で0.48倍速、reports/110)。
