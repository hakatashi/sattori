# th08（東方永夜抄）対応の技術的背景（Issue #13）

touhou-recorder での事前検証（reports/22〜26）を踏まえた th08 固有の設計。**ゲームデータの
バージョンがこのタイトルの肝**で、知らずに触ると成功率が 20% まで落ちる。

- **ゲームデータは公式アップデータ ver1.00d 相当を使う**。ver1.00a はリプレイ再生中に
  内部fpsが数百〜数千に暴走する既知の不具合があり(reports/22)、ver1.00dで事実上
  解消した(成功率20%→100%、reports/23)。タイトル資産アーカイブには `games/th08` と
  してver1.00d相当のデータを配置すること(`upload-title-assets` skill)。
- **fps暴走検知は削除済み**: 上記のver1.00a不具合への対策として、`mods/common/
  fps_monitor.cpp`がGetDeviceStateフックの呼び出し頻度(実効fps相当)を5秒毎にログ出力し、
  `recording.modlog.scan_fps_runaway()`が閾値超過の継続で異常とみなす仕組みを「稀な
  残存ケースへの備え」として残していた。しかし閾値は運用中に2度、会話・演出イベント中の
  良性のポーリング頻度上昇(th08の会話イベントで実測179.9Hz、reports未収載のth09
  ステージ間演出で実測369〜380Hz)を誤って異常と判定し、閾値を100Hz→300Hzへ引き上げても
  なお回避できないケースが出た。実際に本番で発火した2件がいずれも偽陽性で、真陽性の
  実績が皆無だったため、2026-09-08に検知ロジック自体を削除した
  ([`decisions/0043`](../../../docs/decisions/0043-remove-fps-runaway-detection.md))。
  `fps_monitor.cpp`自体は診断用ログとして引き続き動いている。
- **処理落ちの早期検知は廃止済み**: 導入時はth08で高頻度に再発した処理落ち
  (reports/12・13・22)への対策(0.15秒間隔の短時間サンプリング)だったが、真陽性の
  実績が無いまま正常なリプレイ(会話イベント等)を誤検知するリスクが判明したため削除した
  ([`decisions/0038`](../../../docs/decisions/0038-remove-stutter-early-detection.md))。
- **映像/音声を別プロセスで録画**: 単一ffmpegでx11grab(映像)とpulse(音声)を同時に
  取り込むと、内部のA/V同期がth08の描画タイミングを律速し、AWS環境で重複フレーム率が
  85%超まで悪化することが判明した(reports/26)。両タイトルとも既定で映像・音声を別
  プロセスで録画し、停止後に `ffmpeg -c copy -shortest` で結合する(th07はこの問題の
  影響を受けないが、安全側に倒して両タイトル共通の実装にした)。
- **リプレイの正規スロット名**: `th7_ud0000.rpy` と同じ命名則(`th{N}_ud####.rpy`)を
  踏襲し、th08では `th8_ud0000.rpy` を使う。touhou-recorderの検証レポート(22〜26)
  では未検証だった(PoC側は常にゲームデータに元から存在するファイルを使っていたため)
  が、Issue #13対応時に実ゲームデータ(ver1.00d)で実機検証済み(候補スロット名で
  配置したリプレイが実際に選択・再生されることをスクリーンショットで確認した)。
- **自動リトライ**: 既定3回(`recording.pipeline.MAX_ATTEMPTS_DEFAULT`)。th08固有の
  不安定性はver1.00d更新+音声分離修正でおおむね解消された前提のため、旧検証時に
  th08向けに推奨されていた8〜15回のような大きな値は採用せず、th07を含む両タイトル
  共通の既定値としている。
- **日本語フォント（MS ゴシック）の配置・レジストリ登録が必要**。th07 と同じ理由で、
  無いと本番で文字化けする（[`th07.md`](th07.md)）。
- **起動から約2.5秒後にウィンドウ自体を破棄・再生成する**（座標は同じ `(3,29)`）。
  クロップ座標を確定する手順は全ゲーム共通で
  [`docs/decisions/0012`](../../../docs/decisions/0012-crop-geometry-after-window-stabilizes.md)。
- **終了検知**はリプレイ選択画面テンプレート（`assets/replay_end_templates/th08.png`）との
  照合（[`docs/decisions/0011`](../../../docs/decisions/0011-replay-end-template-matching.md)）。
